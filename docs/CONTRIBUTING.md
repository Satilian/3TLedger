# Contributing

Thank you for contributing to 3T Ledger.

---

# Before Writing Code

Ask yourself:

Does this improve

- Transparency?
- Trust?
- Trail?

If the answer is "no",

the feature probably doesn't belong.

---

# Coding Principles

Write code that is:

- simple;
- readable;
- testable;
- maintainable.

Prefer clarity over cleverness.

---

# Pull Requests

Every PR should explain:

- Why?
- What?
- How?

---

# Commit Messages

Use Conventional Commits.

Examples:

feat:

fix:

docs:

refactor:

test:

chore:

---

# Code Review

We review:

- correctness
- simplicity
- architecture
- maintainability

not coding style preferences.

---

# Documentation

Every major feature should include documentation.

Documentation is part of the feature.

---

# Community

Be respectful.

Be constructive.

Assume good intentions.

Help others grow.
