# Миграция дизайн-макетов

Применяется к `design/*.pen` и `design/pages/*.pen`.

- Источник общих токенов, компонентов и layouts — `design/ui-kit.lib.pen`.
- Порядок, чекбоксы и журнал работы находятся в `design/MIGRATION_PLAN.md`. Читать перед началом подпункта и обновлять после его проверки.
- Сохранять существующие данные и композицию; исправлять дефекты без самостоятельного редизайна.
- Использовать библиотечные экземпляры, слоты и overrides. Новые повторяющиеся элементы добавлять в библиотеку без дублирования существующих.
- До удаления исходного макета проверить перенос содержимого и отсутствие зависимостей от удаляемых узлов.
- Не менять другие размеры заранее; общие изменения проверять на уже завершённых макетах.
- Не затрагивать `user-profile.pen`.
- Проверять снимки, переносы, clipping, денежные подписи, разрешение токенов и компонентов. Сохранить и повторно прочитать результат. Проверить Git diff и `git diff --check`.
- Отметить подпункт только после выполнения и проверки; описать ограничения проверки в журнале.
- После подпункта остановиться до коммита для проверки пользователем. Коммитить только после явного разрешения; push не выполнять.
