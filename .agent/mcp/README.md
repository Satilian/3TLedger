# MCP для дизайна

Для работы с `.pen` требуется подключённый MCP pen.dev (в текущей среде инструменты доступны с префиксом `mcp__pencil__`).

Необходимые инструменты:

- `get_app_state` — активный документ и состояние редактора;
- `read_skill` — актуальная схема и инструкции API;
- `execute` — чтение и изменение узлов, токенов и получение снимков;
- `save` — сохранение документа на диск.

Перед работой проверить доступность инструментов и использовать URI целевого документа, а не полагаться на активную вкладку. Изображения из ответа `TakeScreenshot` просматривать как изображения, не печатать base64 в текстовый вывод.

В этой среде запрос закрытого или недоступного URI может вернуть активный документ. Перед изменением, удалением и проверкой результата сверять ожидаемые имена корневых узлов. Одного совпадения ID недостаточно: заготовки разных страниц имеют одинаковые ID. При несовпадении не редактировать документ; открыть нужный файл в редакторе и повторить проверку.

В текущей сессии MCP уже предоставлен средой. Этот файл фиксирует требования, но не устанавливает и не запускает сервер. Адрес, команда запуска и способ авторизации не заданы проектом; не выдумывать их и не менять глобальную конфигурацию. Если MCP отсутствует, сообщить о недоступности редактирования `.pen`; не подменять его прямой записью файла.
